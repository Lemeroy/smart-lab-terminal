# 智能实验室终端设计决策记录

版本 0.1.0，日期 2026-10-12。以下决定构成设计基线，变更须同步需求、接口、训练评估和验收计划。

| 编号 | 决定 | 理由与实现约束 |
|---|---|---|
| ADR-01 | 智能实验室系统建立独立仓库 | AnchorDiff 保持通用算法定位；实验室 UI、课程、身份和设备逻辑只放本仓库 |
| ADR-02 | 以本次有效首拍为位置基线 | 适应每次实验的实际布置，不预设固定归位区；只证明相对状态变化 |
| ADR-03 | 仅识别仪器类别 | 小器件、线缆和个人物品作为残余视觉变化，不声称识别了其类别或数量 |
| ADR-04 | 标记用于几何定位 | ArUco 或 AprilTag 的 ID 只对应桌面锚点；不作为仪器资产 ID |
| ADR-05 | 系统判定，教师只读 | 教师查看和导出，不改写状态或分数；不可靠证据输出不可判定，学生重拍或运维修复 |
| ADR-06 | 默认位置容差 0.1 | 位移按目标框面积平方根归一化；阈值和规则版本冻结在会话中 |
| ADR-07 | 扰乱度输出数值与证据 | 0–1 比较分，不保留整洁度 level；每个对象框和残余框有解释，拒答为 null |
| ADR-08 | 固定或大体固定相机 | 单应性仅补偿桌面平面变化，无法消除高仪器视差；不支持手持任意视角 |
| ADR-09 | 端侧分析，后台归档 | 网络不参与正常推理关键路径；离线会话可完成，同步状态独立于分析状态 |
| ADR-10 | 外部依赖固定到版本 | AnchorDiff 基线 v0.6.1；模型、解码器、相机、规则和配置均保存版本与哈希 |
| ADR-11 | 先统一坐标，再做检测和比较 | 不能把原始图框与对齐后残余混用；可视化须标明坐标系 |
| ADR-12 | 部署目标候选为 RK3588 | 最终板型、相机和镜头须通过真实负载、光照、散热与安装试验决定 |
| ADR-13 | 不将课堂数据默认纳入 Git | 图像、身份映射、权重、密钥与导出报告使用受控存储；私有仓库也执行提交去敏 |
| ADR-14 | 系统仓库保持私有，README 使用中文 | 当前本地维护；后续远端必须设为私有，仅授权成员访问；AnchorDiff 外部公开依赖保持独立 |

## 待实测与待配置事项

| 事项 | 默认建议 | 决定所需证据 |
|---|---|---|
| 镜头位置 | 后上方固定高位，尽量接近俯视 | 全桌可见率、前后遮挡、最高仪器视差、定位框抖动 |
| 图像分析尺寸 | 桌面 ROI 长边 960–1280 像素候选 | 残余最小关注区域与 p95 延迟，不只看检测网络输入尺寸 |
| 检测模型 | 现成轻量 YOLO 微调作为基准 | 真实仪器召回率、同类误匹配、许可证和 RKNN 支持情况 |
| 数据规模 | 先采覆盖变化条件的试采集集，再按学习曲线补充 | 失败类别、相机与课次划分、独立测试置信区间 |
| 质量阈值 | 保留 AnchorDiff 基础门控并增加应用门控 | 重拍率与误判率、相机抖动、手部遮挡、缺锚点样本 |
| 证据留存 | 图像 30 天、结构化记录 180 天作为配置示例 | 学校批准的用途、保留周期与删除要求；不是既定合规结论 |
| 网络与登录 | 校内 HTTPS，在线授权与短期离线凭据 | 现有认证体系、内网部署、课程授权和设备管理方式 |
| 硬件采购 | 先借用相机和 PC 验证，再购买候选开发板 | 安装可行性、驱动、峰值供电、长期温度与维护能力 |

管理员可以新增配置版本，不能覆盖已有会话的配置快照。涉及依赖 API、分数公式、匹配、门控或坐标规则的变化必须重新验收，并明确是否需要新模型或新规则版本。
