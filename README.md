# 智能实验室终端

智能实验室终端将实验资料、开始与结束拍照、仪器位置比较、桌面扰乱度分析和教师记录查看连接成一个完整流程。本仓库用于独立维护系统设计、目标检测训练规范和开发验收计划。

## 业务流程

登录与选择实验 → 首次拍照 → 记录仪器及位置 → 查看资料与清单 → 完成实验并点击结束 → 收台向导 → 结束拍照 → 系统分析仪器位置与桌面扰乱度 → 教师只读查看 → 导出报告用于线下反馈。

首次拍照定义本次比较的位置基线，无须预先划定固定归位区。定位标记只用于图像定位。系统识别仪器类别，其他物品作为未解释的视觉变化记录。

## 与 AnchorDiff 的关系

[AnchorDiff](https://github.com/Lemeroy/anchordiff) 是独立通用算法项目，负责对齐、对象匹配、变化解释、残余区域和扰乱度计算。本项目负责实验室业务、设备、检测模型、交互、权限、记录与报告。两者分别维护，集成基线为 AnchorDiff `v0.6.1`，不得依赖会随时变化的 `main` 分支。

默认位置容差为 `0.1`，定义为中心点位移除以两次目标框面积平方根的较大值。扰乱度使用 `0–1` 数值；证据不可靠时为 `null`，同时标记 `needs_review`。教师不修改系统结果。

## 后续开发入口

按开发计划先进行相机和坐标验证，再实现会话闭环、训练检测模型、接入 AnchorDiff、部署 RK3588、完成后台和试点验收。现有文档不提供未实现的启动命令。

真实桌面照片、身份映射、模型权重、凭据和运行记录默认排除在 Git 之外。训练数据和模型应使用受控存储，演示与共享资料须采用合成或经过授权与去敏的内容。
